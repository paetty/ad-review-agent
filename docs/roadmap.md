# Roadmap

## MVP（当前）

七个页面、13 类 taxonomy、单条/CSV、TF-IDF、本地 Demo Engine、统一 schema、风险后处理、SQLite、复核留痕、固定评测、Prompt 版本、匿名分桶、安全文档与测试。

## P1

- 把已实现的 Provider Adapter 接入主编排并加 mock 集成测试。
- Embedding/TF-IDF 切换、元数据过滤 UI 与检索评测。
- 完整标签/风险/建议编辑表单、逐字段 diff 和复核状态机。
- 异步批处理、进度轮询、筛选排序和前端 CSV 导出。
- 视觉 Provider、图片隔离存储、扫描和保留期限。
- 双版本并排评测、分桶图表和五维人评录入。

## P2

认证、RBAC、审计、队列、生产数据库、对象存储、限流、加密和数据生命周期；在授权前提下做真实匿名试点、样本量估算和因果实验。线上动作仍需审批。
