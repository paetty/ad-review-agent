# 有原始截图对应的公开广告示例

来源：[Ad Perceptions Dataset](https://github.com/eric-zeng/chi-bad-ads-data)。下列ad_id、截图文件名与评论均按原数据的广告ID关联。CHI21记录号是本项目导入器分配的行号，不是原论文的广告ID。

这些是单独的外部研究记录，不是48条合成案例的素材。截图和主观评论不能单独证明违法、频次、跳转或因果。短评论展示英文原文，较长评论标注为中文释义；释义不是原始中文反馈。素材仅通过原仓库链接显示，未下载或复制到本仓库。

## 后续如何扩成可审核案例集

按同一ad_id/creative_id固定关联截图与反馈，单独记录时间、曝光和行为证据是否缺失；先人工确认素材授权与适用标签，再建立任务金标。没有原始素材的反馈，保留素材缺失状态，不补配无关图片。
