# 开源路线图

## v0.1：可演示的审核 Agent（当前）

- FastAPI + Next.js 可运行界面
- LangGraph 节点、状态、条件路由与人工中断
- 本地 TF-IDF RAG、规则引擎、SQLite 和 OpenAI-compatible 适配层
- 文本单条/批量分析、图片基础校验、综合归因、合成评测
- CI、Docker、贡献指南、安全说明和 Issue 模板

## v0.2：增强检索和多模态

- 将内存检查点替换为 SQLite/PostgreSQL 持久化检查点
- 增加 Embedding 召回与 reranker，对比 TF-IDF 基线
- 增加本地 OCR，并将文字证据与图片区域关联
- 把图片审核与综合归因纳入同一 Agent 状态图

## v0.3：可衡量的产品验证

- 建立人工标注规范、双人复核和分歧仲裁
- 在匿名真实样本上报告 Macro F1、高风险 Recall、人工复核 Recall、耗时与成本
- 增加 Prompt/模型/检索策略版本对比和回归门槛

## v1.0：生产化准备

- 登录鉴权、角色权限、审计日志、限流和任务队列
- 持久化对象存储及数据保留/删除策略
- 监控、告警、降级、灰度发布和人工申诉闭环
- 在明确授权后，才连接真实业务系统；默认保持“只建议、不自动处置”

路线图是计划，不代表这些能力已经完成。README 和演示中应始终把“当前能力”与“未来规划”分开描述。
