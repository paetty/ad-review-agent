# 独立评测与留出集协议

当前48条合成样本分为28条development、8条validation和12条holdout_candidate，按24个表达家族分组隔离，没有相同文本跨组。2026-10-22，项目使用者明确确认48条现有参考标注无异议，现已记录reviewed、评审来源及日期，属于单人复核的合成文本参考集。作者和评审者看过参考答案，因此不能宣称它已经是严格独立盲测；holdout_candidate只是历史拆分名称，尚未冻结或执行。

## 建立真正的留出集

1. 由未参与调规则的人另外补充样本，覆盖12问题类、多标签、模糊、否定、正常、图文冲突和高风险隐晦表达。
2. 使用统一标注手册：区分用户声称、素材事实、链路事实；疑似风险与已确认违规分开；证据不足独立标记。
3. 至少两人独立标注并仲裁。暂时没有两人时如实记录单人标注，不能伪称双人。
4. 以广告/素材ID、模板家族或近似文本簇为单位分组，组内样本只属于一个split。外部素材的衍生翻译也留在同一组。
5. 规则、提示词、检索方案在development与validation上选择，最终留出内容不用于调优。确认记录后设置annotation_status=reviewed并记录reviewer，运行 `scripts/evaluate_v2.py --freeze` 记录SHA-256。
6. 留出运行前校验指纹；文件变更后必须重新确认版本。指纹只能检验内容变化，不证明标注者独立或答案正确。

## 当前工具行为

默认只跑development，输出逐条标签/风险和状态差异，不覆盖旧80条报告。未审核/未冻结的holdout_candidate拒绝运行。真实模型需显式--allow-provider。候选分数只能用于开发诊断，不能写成独立测试准确率。

高风险召回按gold_risk与predicted_risk计算，另报告高风险样本数和复核触发召回。零个高风险样本时该召回为null，不虚报100%。真实运行时间与Demo模拟时延分开，未知模型费用为null。

## 下一轮对照

在同一人工确认开发/验证集、相同规则版本与模型配置下，比较规则基线、模型不检索、模型加全部适用规范、模型加TF-IDF，再按失败分布决定Embedding和reranker。除了F1，还看引用支持度、证据不足识别、人工修改量、处理时间和成本。不得只选择成功案例或反复调留出集。
