# 人工标签与建议同步

编辑表单为每条建议预填适用标签，依据建议动作和理由中的有限词语匹配；人工必须核对，可修改关联。未识别的建议保持待确认状态，不默认为所有标签；保存前必须关联或手动删除。关联多个标签的建议只要仍与保留标签相交，就继续保留。自动移除的建议仍在表单可见，重新选择标签可恢复。可以手动删除、恢复或新增建议。

提交时只发送与保留标签有关且未手动删除的建议，以及人工确认的recommendation_label_links。后端校验关联数量、非空和标签范围，修正版与关联写入human_reviews；AI原始标签、建议和证据不覆盖。字段可选以兼容已有API调用者；旧调用者未提供关联时不进行语义自动筛选。此机制按人工标签及关联同步，不从备注自由文本推断或重新生成建议。
