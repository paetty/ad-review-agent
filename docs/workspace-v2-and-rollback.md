# 工作空间 2.0：界面改版与回滚

更新日期：2026-11-03。参考简洁后台、人工标注和 AI 评测工具的信息组织方式，自行实现现有 React/Tailwind 页面，没有复制第三方产品代码，也没有引入新的平台依赖。

## 页面在哪里

| 主模块 | 功能 |
| --- | --- |
| 工作台 | 本地累计记录、风险分布、常用任务入口；没有记录时显示空状态 |
| 分析任务 / 新建分析 | 同一表单选择“分析并人工确认”或“快速分析”；后者保留图片上传接口 |
| 分析任务 / 批量任务 | CSV 逐行分析，原有模板、校验和错误信息保留 |
| 分析任务 / 按广告汇总 | 关联素材与按广告 ID 聚合；与逐行分析区分 |
| 分析任务 / 交接报告 | 反馈表与可选曝光表、问题单、证据核查和报告导出 |
| 人工复核 | 搜索和风险筛选、选中记录、真实编辑标签/风险/建议、保存人工版本 |
| 评测中心 | 原有数据集选择、调用预览、规则/真实模型选择、进度及错误明细 |
| 知识库与配置 | Prompt 版本与切换、标签和知识库说明；匿名分桶收在展开区域 |
| 侧栏底部项目说明 | 背景、事实边界及演示讲解 |

## 交互和口径

- 分析结果默认展示结论、建议和待补信息；原文证据、规范来源、运行详情和执行过程按需展开。
- 保留 `RetainedPage`：切换主模块或子视图不卸载已访问页面，保留输入、文件选择、运行中的请求、结果和编辑草稿。
- 等待人工确认时锁定当前输入，避免在同一表单上覆盖未处理任务。
- 人工复核列表复用既有 `/analyses/{id}/reviews`；“编辑修正版”确实保存修正字段，原始输出不覆盖。标签与建议关联仍需人工核对。
- 顶部统一显示数据和辅助判断边界；模型名、图片能力等放在环境详情。
- 概览接口的 `today_analyses` 实际为累计值，界面改名“累计分析记录”。不展示原有复核记录数/分析数比值，避免被误认为去重后的样本复核率。
- 风险图不再在无数据或请求失败时展示虚构的默认分布。

## 已知边界

- 页面保持不等于服务端持久任务。刷新/关闭浏览器不会恢复表单；Agent 暂停检查点仍在后端内存，服务重启后不能恢复。数据库里已保存的分析/复核保留。
- 复核列表接口仍为按原始需复核标记返回最近 200 条以内，包含历史已处理样本；没有新增服务端跨会话处理状态过滤。界面已明确说明。
- 人工修改不会自动训练模型；接受结果也不会自动处罚、放量或发送报告。
- 本轮没有改检索算法、模型、标签规则或数据库结构。快速分析、暂停复核、批量、聚合、业务报告和评测接口保留。
