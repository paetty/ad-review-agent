# 面试讲解

## 1 分钟

我做了一个广告素材体验分析助手个人作品，解决反馈文本量大、标签不统一、依据难追溯的问题。输入后先做敏感信息拦截和规则预判，再从本地演示规范检索，通过统一 schema 输出多标签、风险、引用和四类建议。critical 或低置信度进入人工复核，修正不覆盖原输出；固定合成集评测高风险 recall、F1、耗时和成本。无密钥使用确定性 Demo Engine，现场可稳定演示。作品只使用公开/合成数据，不接入 vivo 内部系统，不声称真实业务收益。

## 3 分钟

1. 背景：过往商业化经历让我观察到跳转、Deeplink 返回和反馈治理问题，但作品严格不使用内部数据。
2. 用户：商业化 PM、治理、审核、运营。目标不是自动处罚，而是提升归因和策略闭环效率。
3. 链路：校验 → PII → 规则 → TF-IDF → 结构化生成 → schema → 风险升级 → 保存 → 复核 → 评测。引用都能回到真实片段。
4. 取舍：离线 Demo 保证可重复；Provider Adapter 保留切换空间。冲突时风险只升级，高风险动作不执行。
5. 评测：80 条固定合成集，恶意、隐私和返回风险优先 recall；建议另做五维人评。SHA-256 分桶仅演示设计，灰度不等于 A/B。
6. 下一步：视觉、Embedding、真实匿名人评、权限审计和同集版本对照。

## 追问边界

- 是 vivo 内部项目吗？不是，是公开规则与合成数据的独立作品。
- 用了 2,149 条反馈吗？没有；这里只用程序生成的 synthetic records。
- 上线或提升 CTR 了吗？没有可声称的部署或业务提升，只展示本地实测。
- Demo Mode 是模型效果吗？不是，是确定性规则基线，用于演示流程和可靠性。
