# 日常安全检测与策略效果检测

在工作台侧栏选择「监测与策略」。左侧填写自然语言分析要求，右侧上传脱敏 CSV。策略效果检测还需选择上线日期、上线前观察周期、上线后观察周期。两页均可下载合成模板或直接运行合成示例。检测结果保留在当前页面。

## 数据口径

每行对应一个日期、广告 ID 和素材 ID。保留 `date`、`ad_id`、`impressions` 三列。其余字段可以留空。同一广告在一次上传中采用统一粒度：广告汇总留空 `creative_id`，素材明细填写它。

| 字段 | 含义 |
| --- | --- |
| `date`、`ad_id`、`creative_id` | 日期（YYYY-MM-DD）、广告 ID、可选素材 ID |
| `industry` | 行业。按行业筛选时须填写，同一素材的行业口径一致 |
| `impressions`、`revenue`、`spend` | 曝光量、收入、消耗。币种和统计时区在同一张表中保持一致 |
| `ecpm` | 可选。优先用总收入除以总曝光乘 1000，缺收入且逐行 eCPM 完整时按曝光加权 |
| `negative_feedback` | 去重后的反馈事件数。反馈事件率 = 事件数 ÷ 曝光量 × 100%，与人数口径的投诉率有区别 |
| `paying_users`、`eligible_users` | 按同一业务口径提供的分子和分母。显示的是各行计数之和的比率，跨日独立用户需要上游去重 |
| `creative_text`、`feedback_text` | 可选的素材文案与反馈摘要。需要核查画面、音频或跳转实况时，由人工补证据 |

分母为零、存在缺失或无法计算相对变化时显示「不可计算」。缺失的数值留空，已确认的零填 0。表格限制为 UTF-8 CSV、2 MB、200 行，拒绝敏感列、疑似个人标识及重复键。

## 提示词与检测流程

条件提取的提示词位于 `backend/app/diagnostic_requests.py`，摘要提示词位于 `backend/app/diagnostic_prompts.py`。模型先把分析要求提取成结构化条件，服务端检查条件并计算指标，最后让模型引用证据编号给出摘要和建议。

| 任务 | 程序做什么 | 提示词交给模型什么 |
| --- | --- | --- |
| 日常安全检测 `ad-monitor-v1` | 按广告和素材汇总上传窗口，严格筛选曝光大于门槛的记录。高风险文字线索使用既有规则和本地检索。反馈事件至少 3 条且达阈值时，独立提示指标异常 | 根据 A001 等证据说明文字风险、反馈异常和建议优先核查项。曝光、收入与消耗只用于说明范围和影响 |
| 策略效果检测 `ad-strategy-v1` | 校验上线日期、前后窗口、覆盖天数、最低曝光和素材范围。计算 M01 等指标证据以及 D01 样本口径，分别检查反馈目标与商业护栏 | 解释目标变化、护栏和数据限制，引用相应证据，建议补数、继续观察或人工评估回滚 |

日常检测合成示例中，一个素材有可疑跳转文字线索，一个素材触发反馈事件率阈值，另一个素材低于曝光门槛。策略效果合成示例以上线日 2026-11-07 为界，比较 11-01 至 11-03 与 11-08 至 11-10。反馈事件率改善，日均收入和 eCPM 触线，结论为「触发护栏，人工评估回滚」。前后对比用于观察变化，归因还需要对照实验或其他可靠的验证设计。

历史对比以 CSV 中所选范围的最新日期为基准。可写「最近 3 天」和「此前 30 天」控制窗口。未指定当前周期时取最新一天，未指定历史天数时使用此前已有数据。按同一素材汇总反馈事件与曝光计算基线。明确要求的观察天数未覆盖时，历史差值显示不可计算。

## 模型调用

提交自然语言要求后，已配置的模型自动参与条件提取和摘要，通常各调用一次。现有适配器在限流或超时时最多尝试三次。模型收到分析要求、可选行业名和匿名结构化指标。原始 CSV、素材原文和表中的广告 ID 留在本机处理。模型暂不可用时，服务端可提取常见的曝光下限、已有行业、历史窗口与显式阈值，结果会标明规则处理状态。

策略的计算结果、告警和状态由程序给出，团队根据证据决定是否采取行动。

## 可复现测试案例

| 用例 | 操作 | 预期 |
| --- | --- | --- |
| 日常条件与历史对比 | 日常安全检测运行默认合成示例 | 筛选电商行业最近 3 天曝光大于 1 万的素材，展示同素材历史基线和证据 |
| 严格门槛 | 输入「检查电商行业最近3天曝光量大于六万的素材，比较历史平均」后运行合成示例 | 曝光恰好 6 万的 DEMO-B 被筛除。把「大于」改成「至少」后会入选 |
| 历史覆盖不足 | 输入「检查电商行业最近3天曝光量大于一万的素材，和此前30天的历史平均比较」 | 历史覆盖不满足要求，历史差值显示不可计算 |
| 历史风险升高 | 使用 `backend/tests/test_diagnostics.py` 中的 `HISTORY_CSV` 并要求比较电商素材历史平均 | AD-H 的反馈事件率由 0.50% 升至 1.50%，升 1 个百分点。无历史的 AD-N 显示不可计算 |
| 策略目标与护栏 | 策略效果检测运行默认合成示例 | 页面填入上线日与两个周期。反馈改善与商业护栏触线同时显示，建议人工评估回滚 |
| 日期边界 | 上传模板，把上线前观察周期的结束日期设为上线当天，再提交 | 提示检查观察窗口，避免将上线当天算入上线前 |
