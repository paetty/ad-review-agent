# Experiment Design

输入 `anonymous_user_id`，后端计算 `SHA-256(salt + anonymous_user_id)`，映射到 0–99：0–59 为 `treatment_main`，60–69 为 `treatment_small`，70–99 为 `control`。相同 ID 与 salt 稳定分组，三个组互斥；数据库只存匿名 ID 的单独 SHA-256 哈希、桶和组，salt 不返回前端。

单元测试验证稳定性、互斥性，并以 20,000 个合成匿名 ID 检查比例近似 60% / 10% / 30%。这只是实验设计演示，不连接真实用户或设备标识。

灰度发布强调逐步放量与风险控制，不天然产生可比较的随机对照，因此不等于 A/B 测试。因果评估还需明确随机分流单位、主指标、护栏指标、样本量、实验周期、污染与多重检验处理。
