# 失败案例分析

案例来自 synthetic/demo 测试设计，不代表真实线上事故。

## 1. 检索正确但生成结论错误
- 现象：召回返回规范，却只标记跳转。
- 根因：模型偏向显眼关键词。
- 影响：缺少缩短返回路径动作。
- 修复：多标签 schema、规则后处理、复合样本。
- 修复后结果：“自动跳转且返回很多次”稳定输出两个标签。

## 2. 召回错误导致建议偏离
- 现象：素材“重复”误召回频率规范，只建议频控。
- 根因：重复曝光与重复创意词义接近。
- 影响：素材疲劳未解决。
- 修复：知识库明确边界，显示真实 score。
- 修复后结果：Demo Engine 区分频率与素材重复，人工仍可纠正。

## 3. 多标签漏检
- 现象：恶意重定向同时索取通讯录，只识别恶意链路。
- 根因：单标签偏好和高风险竞争。
- 影响：隐私核查缺失。
- 修复：逐标签匹配、多标签黄金样本、互斥测试。
- 修复后结果：两标签共存，整体 critical 并强制复核。

## 4. 模糊反馈过度推断
- 现象：“感觉奇怪”被断言恶意跳转。
- 根因：补全了输入没有的事实。
- 影响：误拦截与审核成本。
- 修复：证据白名单；无明确风险时 no_issue + uncertainty。
- 修复后结果：10 条模糊样本不凭空生成恶意证据。

## 5. 规则与模型冲突
- 现象：malicious 标签却为 medium 且无需复核。
- 根因：生成字段不一致。
- 影响：高风险绕过队列。
- 修复：风险只升级，critical 强制人工复核。
- 修复后结果：测试验证恶意/隐私升级为 critical，并含 P0 核查建议。
