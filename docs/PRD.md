# PRD：广告素材体验分析与策略建议助手

## 背景与机会

广告反馈常散落在自由文本、素材说明和运营记录中。人工阅读慢、标签口径不一、结论难追溯、治理建议难形成闭环。作者过往接触过 SSP/ADX/DSP、广告跳转返回体验和反馈分析；本作品只把观察转化为公开可演示的方法，不复刻任何公司内部系统或数据。

## 用户、痛点与范围

| 用户 | 核心任务 | 痛点 |
|---|---|---|
| 商业化产品经理 | 定义策略与权衡 | 建议缺少证据和护栏 |
| 体验治理 | 发现高风险问题 | 标签不统一、漏检代价高 |
| 内容审核 | 复核模型结论 | 原始输出易被覆盖 |
| 广告运营 | 批量整理反馈 | 字段混乱、敏感数据风险 |

MVP 包括单条/批量分析、本地规则检索、多标签与风险判断、四类建议、人工复核、合成评测、Prompt 版本、匿名分桶和删除。非目标包括真实投放、自动处罚、自动改线上策略、采集个人标识、替代法务/审核、爬取受限页面。

## 用户故事与流程

1. 治理人员上传不含 PII 的 CSV，看到逐行结果和错误行。
2. 审核人员查看 high/critical 或低置信度样本，修正且保留差异。
3. 产品经理能追溯每条结论到输入和演示规范。
4. AI 产品经理能在固定合成集比较 Prompt/模型，同时看 recall、成本和护栏。

流程：输入 → PII 拦截 → 规则预判 → 本地检索 → 结构化生成 → schema 校验 → 风险升级 → 保存 → 复核 → 评测。

## 指标与风险

- 效果：per-label P/R/F1、macro/micro F1、exact match、高风险 recall、复核触发 recall。
- 效率：平均耗时、批量成功率、人工复核率；成本：Token 与单次估算。
- 建议人评：正确性、完整性、可执行性、证据一致性、安全性，各 1–5 分。
- 护栏：误拦截率、审核误杀率、可投覆盖率、返回误触率。

主要风险是过度推断、引用不实、高风险漏检、隐私泄漏和自动化越权。验收要求引用可追溯、critical 强制复核、PII 阻止、原始/修正版并存和测试通过。
