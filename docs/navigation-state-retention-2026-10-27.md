# 菜单切换保留当前工作

## 修复

旧Dashboard按当前page条件渲染各组件，切换会卸载，导致本地表单、文件选择、Agent任务ID、等待状态和结果丢失。卸载并不保证取消后端请求；可能仍在后端执行，但前端无法再展示其结果。

新增RetainedPage，各页首次访问时才挂载，之后隐藏而非卸载，隐藏页不参与可视交互。页面内异步响应可继续更新本地状态；返回时保留输入、结果、选中文件和人工编辑草稿。首次访问仍正常加载数据，切换回来不自动重新请求或重复提交。此为当前浏览器页面会话内保留，不是浏览器刷新持久化，也不是后端任务队列。刷新、关闭或后端重启仍有原有边界；长期运行企业版本应改用持久化任务ID及状态查询。

## 验证

浏览器4项通过：原有正常/延迟/失败接口页面切换检查，以及新增Agent结果和输入保留、业务请求等待期间切换后仍得到报告、不重复提交。测试使用已安装Playwright，所有API都由夹具拦截，模型调用为0。前端8项单元测试和修改组件ESLint通过；生产构建通过。实际业务后端任务不中断的生产级保证未作承诺。

## 数据解释

业务闭环曝光表匹配广告ID、素材ID、媒体场景、平台及时间窗；完整覆盖且曝光大于0时，计算反馈事件数/曝光次数*10000。缺失、抽样、未知覆盖、零曝光均不计算。该指标不是独立用户投诉概率，也不是已核实违规率。

当前未实现曝光量门槛的分析前筛选。后续可按同口径曝光量设分析优先级，同时保留低曝光的高风险案例通道。批量分析逐行输出；综合归因按ad_id汇总；业务闭环用更细的复合维度形成问题单。
