# Agent人工编辑与补充开发检查

## 编辑行为

Agent工作台点击“修改后继续”后展开表单，可修改13类标签、风险、建议动作、建议理由和备注。“保存修正并继续”将字段提交至恢复接口。后端验证标签白名单、no_issue互斥及必要编辑字段；失败请求不消耗等待中的中断。

响应中的output保留AI原始输出，corrected_output为人工修正版；human_reviews另外保存修正版与备注。人工修改不会更新模型或修改原始分析表。高风险标记仍保留，不等同于实际广告放行。检查点仍在进程内存，重启不能恢复，但数据库记录保留。

## 开发样例

新增12条合成开发样例由项目使用者在聊天中逐条确认，属于单人复核；未修改旧评测集或留出集。规则基线12条中6条四项同时符合参考。真实模型只调用S01/S08/S09三条，2条四项同时符合参考；这三条的规则基线为1/3。四项是标签、风险、证据状态、复核触发，不包括建议质量或实际素材事实核验。不能当作独立准确率或模型普遍收益。

真实模型qwen3.7-plus，共3次成功调用，输入3818 Token、输出1076 Token、合计4894 Token。API时延分别8775/7760/6018ms。费用未对账，保持null。此次使用隔离内存数据库及显式supplement-check-v1检查提示词，不修改在线Prompt版本或业务记录。

失败：S05漏掉活动过期；S08模型原始仅识别可疑网站，但规则误判否定跳转，合并后多出标签；S09规则把模糊怀疑误视为未见问题，模型链路正确标记证据不足；S10否定通讯录索取仍误报隐私风险；S11漏返回问题；S12漏定位风险。没有为改善分数改动参考答案或规则。下一步按错误层单独修复，并保留原始结果作回归对照。
